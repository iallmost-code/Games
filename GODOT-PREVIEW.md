# Ember Crypt Godot PC Preview

Download `Ember-Crypt-Godot-PC-Preview.zip` from this branch using GitHub’s Download raw file button. Extract it, open Godot 4.6+ Standard, import `EmberCryptGodotPreview/project.godot`, and press F5.

This standalone playable 2.5D Bloodknight/Ash dungeon preview is a visual experiment, not a full port. It does not change the browser game or import its saves.

Controls: WASD/arrows move, Space dash, E ultimate, Esc pause, R restart.

Validation: 31 Godot integration checks passed, fresh ZIP extraction/import passed, and native Compatibility rendering was checked on Linux. Windows hardware performance has not been measured. The archive includes setup instructions, screenshots, and validation reports.
